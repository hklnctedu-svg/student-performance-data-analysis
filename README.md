# Student Performance Data Analysis

## About the Project
This beginner-friendly Python project analyses fictional student marks to explore basic data analysis and visualization.

## Objectives
- Calculate total and average marks for each student.
- Determine pass/fail status using a defined passing rule.
- Identify the highest-performing student.
- Compare subject-wise average marks.
- Visualize performance using charts.
- Export the analysis results to a CSV file.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Google Colab / Jupyter Notebook

## Project Workflow
1. Create and organize the dataset.
2. Calculate totals and averages.
3. Apply pass/fail conditions.
4. Generate summary statistics.
5. Create charts for performance comparison.
6. Export the results to CSV.

## Dataset
The project uses fictional student names and marks for demonstration purposes.

## How to Run
1. Open the `.ipynb` notebook in Google Colab or Jupyter Notebook.
2. Run the cells in order.
3. Review the printed analysis and charts.
4. The program generates a CSV report.

## Learning Outcomes
This project provides practice with Python data structures, Pandas DataFrames, conditional logic, summary statistics, data visualization, and CSV file handling.
